# DjangoWebGold — Архитектура проекта

## Общее описание

**DjangoWebGold** — это веб-сайт ювелирного магазина, написанный на Django (≈4.2). Проект представляет собой **полноценный MVP** (минимально жизнеспособный продукт) с:

- Каталогом товаров с фильтрацией
- Корзиной покупок (требуется авторизация)
- Избранным/закладками (требуется авторизация)
- Отзывами на товары
- Тёмной и светлой темой оформления
- Кастомной системой регистрации (вход по email)

## BACKEND (Django)

### Структура приложений

Проект состоит из **5 кастомных приложений**:

| Приложение | Назначение | Модели |
|---|---|---|
| `main` | Ядро магазина | `Product` |
| `users` | Пользователи | `CustomUser` |
| `cart` | Корзина | `CartItem` |
| `favorites` | Избранное | `Favorite` |
| `reviews` | Отзывы | `Review` |

### Модели данных

**Product** (`main/models.py`) — основной товар:
- `name`, `category` (ring/earrings/necklace/bracelet), `material` (gold/silver/rose/platinum/black/meteorite)
- `price`, `description`, `characteristics`, `image`
- `is_new`, `is_bestseller` — флаги для маркировки
- Упорядочены по `-created_at`

**CustomUser** (`users/models.py`) — расширяет `AbstractUser`:
- `username` — не уникальный
- `email` — уникальный, используется для входа (`USERNAME_FIELD = 'email'`)

**CartItem** (`cart/models.py`):
- `user` (FK) → `product` (FK) → `quantity`
- Метод `total()` = `price * quantity`

**Favorite** (`favorites/models.py`):
- `user` + `product` с `unique_together`
- Один пользователь — одна отметка "в избранном" на товар

**Review** (`reviews/models.py`):
- Хранит отзыв на уровне материала/категории (а не на конкретный товар)
- `product_type`, `material`, `product_name`, `author_name`, `author_email`, `topic`, `text`, `rating` (1–5), `is_published`

### Views (все — function-based)

**main/views.py:**
- `home()` — читает cookie `theme`, рендерит `blackhole.html` (тёмная) или `home_light.html` (светлая)
- `catalog()` — список товаров с GET-фильтрацией по `category` и `material`
- `product_detail()` — один товар по ID
- `register()` — регистрация + авто-логин
- `about()`, `contact()` — статические страницы

**cart/views.py** — все с `@login_required`:
- `cart_view()` — показывает корзину (рендерит `main/index.html`)
- `add_to_cart()` — добавляет/увеличивает количество
- `update_cart()` — меняет количество (POST)
- `remove_from_cart()` — удаляет позицию

**favorites/views.py** — все с `@login_required`:
- `favorites_view()` — список избранного
- `add_to_favorites()` / `remove_from_favorites()`

**reviews/views.py:**
- `reviews_list()` — опубликованные отзывы + средний рейтинг + распределение по звёздам
- `add_review()` — POST-обработчик добавления

**users/views.py** — дублирует функционал из main, НО эти URLs нигде не подключены (мёртвый код).

### URL-маршрутизация

```
/                        — home
/catalog/                — каталог
/catalog/<id>/           — детальная страница товара
/about/                  — о компании
/contact/                — контакты
/login/                  — вход (django.auth.LoginView)
/logout/                 — выход (django.auth.LogoutView)
/register/               — регистрация
/admin/                  — админ-панель
/cart/                   — корзина
/cart/add/<id>/          — добавить в корзину
/cart/update/<id>/       — обновить количество
/cart/remove/<id>/       — удалить из корзины
/favorites/              — избранное
/favorites/add/<id>/     — добавить в избранное
/favorites/remove/<id>/  — удалить из избранного
/reviews/                — отзывы
/reviews/add/            — добавить отзыв
/media/<path>            — медиа-файлы
```

### Формы

**users/forms.py:**
- `CustomAuthenticationForm` — вход по email (поле username заменено на EmailField)
- `CustomUserCreationForm` — регистрация с валидацией:
  - Username: только кириллица/латиница/цифры/пробелы/`. -_`
  - Email: без кириллицы, проверка DNS (через `socket.gethostbyname`), белый список доменных зон, проверка уникальности
  - Подтверждение пароля

### Админ-панель

- **ProductAdmin**: поля для поиска (`name`, `description`), фильтры (`category`, `material`, `is_new`, `is_bestseller`), редактирование цены/флагов из списка
- **CustomUserAdmin**: поиск по email/username, кастомные `fieldsets`
- **Review**: базовая регистрация (`admin.site.register`)
- Cart/Favorites: не зарегистрированы

### Примечания по архитектуре Backend

1. **Дублирование регистрации**: есть 2 `register()` — в `main/views.py` (подключён) и `users/views.py` (не подключён)
2. **Мёртвый код**: `users/urls.py` определён, но нигде не включён в корневой `urls.py`
3. **Отзывы не привязаны к Product**: модель Review хранит `product_type` + `material` + `product_name` строкой, а не ForeignKey. Это значит, что отзыв не привязан к конкретному товару в БД, только к описательным полям.

## FRONTEND

### Базовая структура

Все шаблоны наследуются от **`layout.html`**, который содержит:
- Боковое меню (сайдбар) с навигацией
- Переключатель темы (тёмная/светлая)
- Подключение Bootstrap 5.3.8, Bootstrap Icons, Three.js

**Ни один CSS не вынесен во внешние файлы** — все стили (включая адаптивность) встроены в `<style>` теги внутри шаблонов. Единственный внешний `main.css` — 59 строк, практически не используется.

### Тёмная тема (blackhole.html)

**Главная страница** в тёмном режиме — это Three.js 3D-сцена с чёрной дырой:
- 8000 фоновых звёзд + 5000 дальних звёзд (Points)
- Ядро чёрной дыры (сфера с emissive материалом) — сфера Шварцшильда
- Аккреционный диск — кастомный ShaderMaterial с эффектом Доплера (красный/синий сдвиг по краям)
- Два тонких кольца (TorusGeometry)
- 6000 частиц в диске
- PointLight с анимированной интенсивностью
- OrbitControls с auto-rotate
- EffectComposer + UnrealBloomPass (свечение)
- Адаптивный resize
- Анимация отрисовывается в `requestAnimationFrame` через `renderer.setAnimationLoop`

### Светлая тема (home_light.html)

**Главная страница** в светлом режиме:
- CSS-градиентный фон (летнее небо/закат)
- 80 частиц-искр, создаваемых через JavaScript при загрузке DOM
- Анимированные CSS-элементы (солнце, облака)

### Каталог (catalog.html)

- Сетка товаров (CSS Grid/Flex)
- Фильтры по категории и материалу (GET-параметры)
- Карточки товара: изображение, название, цена, флаги `is_new`/`is_bestseller`
- Кнопки "В корзину" и "В избранное"

### Детальная страница товара (product_detail.html)

- Изображение товара
- Название, цена, описание, характеристики
- Кнопки добавления в корзину и избранное

### Отзывы (reviews_list.html) — 1039 строк, самый сложный шаблон

- **Фон**: анимированные звёзды через canvas (250 малых + 40 крупных)
- **Сводка**: средний рейтинг + распределение по звёздам (график)
- **Карточки отзывов**: бегущая строка (marquee) с градиентными border-эффектами
- **Модальное окно**: форма добавления отзыва с валидацией
- **Звёздный рейтинг**: интерактивный (hover + click) через JavaScript
- **Валидация email**: без кириллицы, плюс regex-проверка
- **Превью цвета материала**: при выборе материала показывается цвет

### Корзина (index.html)

- Таблица с товарами, количеством (поле ввода + кнопки +/—) и ценой
- Итоговая сумма
- Кнопка оформления (заглушка)

### Избранное (favorites.html)

- Сетка карточек с hover-эффектами
- Кнопка удаления из избранного

### Навигация

- Боковое меню (сайдбар) присутствует на всех страницах
- Стили сайдбара различаются в тёмной и светлой теме

### Система тем

Переключение темы работает через:
1. JavaScript: `toggleTheme()` — переключает класс `light-theme` на `<html>`, сохраняет в `localStorage` и устанавливает cookie `theme`
2. После переключения страница перезагружается (`location.reload()`)
3. Сервер читает cookie `theme` и выбирает шаблон для `home()`
4. Стили всех остальных страниц также подстраиваются через CSS-переменные и класс `light-theme`

### Frontend-зависимости (CDN)

- Bootstrap 5.3.8 CSS
- Bootstrap Icons 1.11.0
- Three.js 0.160.0 (ESM)
- Three.js аддоны: OrbitControls, EffectComposer, RenderPass, UnrealBloomPass

## TESTS (Тесты)

### Состояние: тестов НЕТ

Все 5 файлов `tests.py` содержат только одну строку:

```python
from django.test import TestCase
```

Ни одного реального тест-кейса не написано. Это означает:
- Нет тестов моделей (валидация, методы)
- Нет тестов views (статус-коды, контекст, редиректы)
- Нет тестов форм (валидация, ошибки)
- Нет тестов URL-маршрутизации
- Нет тестов авторизации/доступа (`@login_required`)
- Нет тестов корзины/избранного (CRUD-операции)

## ИТОГО: Ключевые особенности

1. **Стек**: Django 4.x, SQLite, Bootstrap 5, Three.js
2. **Аутентификация**: кастомный User (email как логин)
3. **Тема**: переключение тёмной/светлой темы с сохранением в cookie + localStorage
4. **3D-графика**: Three.js чёрная дыра на главной странице (тёмная тема)
5. **Отзывы**: не привязаны к Product FK, хранятся на уровне категория+материал
6. **Мёртвый код**: `users/urls.py` не подключён, есть дублирующийся `register()`
7. **Тесты**: отсутствуют полностью
8. **Docker**: отсутствует
9. **REST API**: отсутствует (нет DRF)
10. **CSS/JS**: всё встроено в шаблоны, внешних статических файлов почти нет
